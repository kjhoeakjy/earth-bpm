# Earth BPM

USGS의 실제 지진 기록으로 지구의 심장 소리를 들려주는 한 장짜리 웹 페이지예요.
지진 하나가 음표 하나가 되고, 그 시간대에 지진이 많고 클수록 지구의 심박(BPM)이 빨라져요.

바로 보기: https://kjhoeakjy.github.io/earth-bpm/

웹 서버(GitHub Pages 같은 곳)에서 열면 모든 기능이 동작해요. `index.html`을 파일로 바로 열어도 실행되지만, 그때는 브라우저가 `voices/` 폴더의 악기 소리를 불러오지 못해서 우주 신스 소리로 대신 연주해요. 내 컴퓨터에서 악기까지 들으려면 폴더에서 `python3 -m http.server`를 실행하고 http://localhost:8000 을 열면 돼요. 3D 그래픽 라이브러리(three.js)와 글꼴은 인터넷에서 불러와요.

## 들어 있는 것

- **시간 여행** : 최근 24시간, 최근 7일(규모 4.5 이상), 그리고 2004 수마트라-안다만 · 2011 동일본 · 2015 네팔 고르카 · 2016 경주 · 2023 튀르키예·시리아 · 2025 캄차카 대지진 전후의 실제 기록을 골라 그때 지구가 냈을 소리를 들을 수 있어요.
- **악기** : 전자키보드처럼 번호가 붙은 20가지 음색과 4가지 박자 소리 중에서 골라요. 자세한 건 [악기 고르기](#악기-고르기)에 있어요.
- **내 지진대** : 지역 하나를 입양하면 그곳이 흔들릴 때마다 나만의 멜로디가 울리고 지구 위에 하트가 피어나요. 이름도 지어줄 수 있어요.
- **지구 일기** : 고른 기록에서 가장 큰 지진, 가장 깊은 지진, 가장 바빴던 한 시간, 최고 심박을 계산해 보여줘요.
- **지구 속 보기** : 지구를 투명하게 해서 지진이 난 깊이를 보여줘요. 깊이는 4배로 과장했어요.
- 지구본의 낮과 밤은 재생 중인 시각의 실제 태양 위치로 그리고, 밤 쪽에는 도시 불빛이 켜져요.
- BPM 상자에는 심박에 맞춰 뛰는 심전도 모니터가 있고, 지구 둘레의 빛 고리는 지금 나는 소리의 주파수 스펙트럼이에요. 연달아 일어난 두 지진은 빛의 호로 이어지고, 큰 지진의 진앙에는 조준 표시가 따라붙어요.

## 악기 고르기

오른쪽 메뉴(휴대폰은 `시간 여행 · 메뉴`)의 `악기` 탭, 아래쪽 초록 LCD 창의 ◀ ▶ 버튼, 또는 키보드 `[` `]`로 바꿔요. LCD 창을 누르면 악기 탭이 열리고, `데모 연주`로 미리 들어볼 수 있어요. 고른 악기와 박자는 브라우저에 기억돼요.

| 번호 | 악기 | 번호 | 악기 |
| --- | --- | --- | --- |
| 000 | 지구 오케스트라 (기본) | 010 | 칼림바 |
| 001 | 그랜드 피아노 | 011 | 클래식 기타 |
| 002 | 일렉트릭 피아노 | 012 | 하프 |
| 003 | 쳄발로 (하프시코드) | 013 | 현악 합주 |
| 004 | 파이프 오르간 | 014 | 첼로 |
| 005 | 첼레스타 | 015 | 브라스 |
| 006 | 오르골 | 016 | 트럼펫 |
| 007 | 비브라폰 | 017 | 플루트 |
| 008 | 마림바 | 018 | 합창 |
| 009 | 차임벨 | 099 | 우주 신스 (처음 버전의 전자음) |

- **지구 오케스트라**는 깊이마다 악기가 달라요. 얕은 지진은 하프, 중간은 비브라폰, 깊어지면 합창과 첼로가 받아요.
- **박자**는 심박을 어떤 소리로 낼지 골라요. 청진기 심장(기본), 팀파니, 콘트라베이스, 전자 킥, 박자 끄기가 있어요.
- 악기 소리는 FluidR3 GM 사운드폰트(Frank Wen, MIT 라이선스)로 음마다 녹음해 둔 것이에요. 악기 하나에 0.2–0.5 MB이고, 고른 악기만 그때그때 불러와요.

## 대지진 연출

규모 6.4 이상의 주요 지진과 규모 7 이상의 지진이 울리면 화면이 달라져요. 규모가 클수록 세져요.

- 진앙에서 섬광이 터지고, 화면을 일그러뜨리는 충격파가 퍼지고, 불씨가 튀고, 카메라가 흔들려요.
- 규모 7 이상이면 화면 가장자리가 심박에 맞춰 붉게 경보를 울리고, 잠깐 느린 화면이 되고, 화면 글자들이 흔들리고, BPM 상자가 빨갛게 변해요.
- 규모 7.5 이상이면 땅이 갈라지는 소리와 느린 두 번째 물결이 더해지고, 규모 숫자가 지직거리며 크게 떠요.
- 기기에서 '동작 줄이기'를 켜 두면 흔들림과 충격파는 빼고 섬광도 약하게 보여줘요.

## 소리와 그림의 규칙

| 데이터 | 소리 | 그림 |
| --- | --- | --- |
| 규모 | 클수록 낮은 음 (라단조 5음 음계, M9 ≈ C2, M1 ≈ G5), 클수록 밝고 길게 | 물결이 퍼지는 거리와 빛기둥 높이 |
| 깊이 | 깊을수록 어둡고 부드럽게 시작해요. 지구 오케스트라에서는 0–20 km 하프 · 20–100 km 비브라폰 · 100–300 km 합창 · 300–700 km 첼로, 우주 신스에서는 지각의 현 · 맨틀의 종 · 깊은 합창 · 심연의 고래 | 노랑(얕음) → 빨강 → 보라 → 하늘색(깊음) |
| 위치 | 화면 왼쪽 지진은 왼쪽 귀에서, 지구 반대편 지진은 먹먹하게 | 지구 위 진앙 |
| 활동량 | 심박 = 56 + 9√(직전 1시간 활동량), 큰 지진은 한 박자 멎었다 크게 뜀 | 대기와 핵이 심박에 맞춰 빛남 |
| M5.2 이상 | 낮은 울림, M6 이상은 징, M7 이상은 여운, M7.5 이상은 갈라지는 소리 | M6 이상은 P파·S파 두 겹의 물결, M6.4 이상은 [대지진 연출](#대지진-연출) |

시간은 지진 사이 간격을 로그로 줄여서 재생해요. 그래서 여진이 몰린 시간은 촘촘하게, 조용한 시간은 짧게 지나가요.

## 데이터

- 최근 24시간·7일 : [USGS 실시간 지진 피드](https://earthquake.usgs.gov/earthquakes/feed/v1.0/csv.php)와 FDSN 카탈로그, 2026년 10월 16일 08:58(한국 시각)까지의 기록
- 과거 대지진 : [USGS FDSN 지진 카탈로그](https://earthquake.usgs.gov/fdsnws/event/1/)
- 육지 윤곽 : Natural Earth 110m ([world-atlas](https://github.com/topojson/world-atlas))
- 악기 소리 : FluidR3 GM 사운드폰트 (Frank Wen, MIT 라이선스)

페이지는 받아 둔 기록으로 동작하고, 브라우저가 USGS에 직접 접속할 수 있는 곳(GitHub Pages 같은 일반 웹 서버)에서는 1분마다 USGS 실시간 피드를 확인해요. 이때 화면 위쪽 표시가 `실시간 · USGS 피드`로 바뀌고, `지금으로 가기`를 누르면 현재 시각에서 다음 지진을 기다려요. USGS에 새 지진이 올라오면 신호음과 함께 바로 물결과 소리로 울려요.

지진은 일어나고 몇 분에서 수십 분 뒤에 피드에 올라오고, 늦게 올라온 지진이 먼저 올라온 지진보다 앞선 시각일 때도 많아요. 그래서 새로 올라온 지진은 일어난 시각과 상관없이 들어온 순서대로 울려요. 작은 지진까지 합쳐도 보통 몇 분에 하나꼴로 들어와요.

## 다시 만들기

```sh
python3 build.py                        # data/, voices/voices.json, src/로 index.html을 다시 만들어요
python3 build.py --artifact out.html    # claude.ai 아티팩트용 조각 HTML
python3 build.py --three ./three        # three.js를 CDN 대신 다른 주소에서 불러오기
python3 tools/render_voices.py          # 악기 소리(voices/*.mp3) 다시 녹음하기
python3 tools/render_voices.py harp     # 하프만 다시
```

- `src/earth-bpm.template.html` : 화면, 3D 그래픽(three.js r128, 셰이더, 블룸), Web Audio 음향 코드
- `data/*.csv` : USGS 지진 기록 (time, latitude, longitude, depth, mag, id, place)
- `data/land.json` : 육지 윤곽 좌표
- `voices/*.mp3` : 악기마다 한 파일. 라단조 5음 음계 28음(A1–D7)을 한 칸에 하나씩 녹음했어요. `voices.json`에 음 목록과 칸 길이가 있어요.
- `build.py` : 기록을 정리해 템플릿에 넣는 스크립트 (파이썬 표준 라이브러리만 사용)
- `tools/render_voices.py` : 사운드폰트로 악기 소리를 녹음하는 스크립트. fluidsynth, ffmpeg, FluidR3_GM.sf2가 필요해요 (Ubuntu: `sudo apt install fluidsynth fluid-soundfont-gm ffmpeg`).

과거 기록에는 많은 사람의 아픔이 함께 남아 있어요. 그날을 기억하는 마음으로 들어주세요.
